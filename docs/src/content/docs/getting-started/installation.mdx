style-this is split into a few packages. They're released in lockstep, always use the same version
for every `@style-this/*` package.

| Package | Purpose |
| --- | --- |
| `@style-this/core` | `css`, `mergeStyles`, `extraClass` and the compiler. Always required. |
| `@style-this/vite` | Vite plugin (Vite, SolidStart, SvelteKit, ...). |
| `@style-this/next` | Next.js integration (webpack and turbopack). |
| `@style-this/react` | `styled` components for React. |
| `@style-this/solid` | `styled` components for SolidJS. |
| `@style-this/webpack` | webpack plugin, also used by `@style-this/next`. |

<Steps>

1. Install the core package and the integration for your bundler.

   <Tabs syncKey="bundler">
   <TabItem label="Vite">
   ```bash
   pnpm add @style-this/core
   pnpm add -D @style-this/vite
   ```
   </TabItem>
   <TabItem label="Next.js">
   ```bash
   pnpm add @style-this/core @style-this/next
   ```
   </TabItem>
   <TabItem label="webpack">
   ```bash
   pnpm add @style-this/core
   pnpm add -D @style-this/webpack
   ```
   </TabItem>
   </Tabs>

2. Optionally install styled components for your framework.

   <Tabs syncKey="framework">
   <TabItem label="React">
   ```bash
   pnpm add @style-this/react
   ```
   </TabItem>
   <TabItem label="Solid">
   ```bash
   pnpm add @style-this/solid
   ```
   </TabItem>
   <TabItem label="Svelte">
   Nothing to install, use `css` from `@style-this/core`.
   </TabItem>
   </Tabs>

3. Register the plugin.

   <Tabs syncKey="bundler">
   <TabItem label="Vite">
   ```ts title="vite.config.ts"
   import { defineConfig } from "vite";
   import react from "@vitejs/plugin-react";
   import styleThis from "@style-this/vite";

   export default defineConfig({
     plugins: [react(), styleThis({ filter: /\.tsx$/ })],
   });
   ```
   `filter` limits the transform to files that contain styles, see
   [`filter`](/reference/vite/#filter).
   </TabItem>
   <TabItem label="Next.js">
   ```js title="next.config.mjs"
   import { withStyleThis } from "@style-this/next";

   /** @type {import('next').NextConfig} */
   const nextConfig = {};

   export default withStyleThis(nextConfig);
   ```
   </TabItem>
   <TabItem label="webpack">
   ```js title="webpack.config.js"
   import { StyleThisPlugin } from "@style-this/webpack";

   export default {
     // ...
     plugins: [new StyleThisPlugin()],
   };
   ```
   The generated CSS is imported as `.css` files, so the config needs a CSS rule, see
   [`@style-this/webpack`](/reference/next-webpack/#style-thiswebpack).
   </TabItem>
   </Tabs>

4. Write a style and use the returned class name.

   ```tsx
   import { css } from "@style-this/core";

   const title = css`
     font-size: 2rem;
     color: rebeccapurple;
   `;

   export const Title = () => <h1 className={title}>Hello</h1>;
   ```

</Steps>
