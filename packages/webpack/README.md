# @style-this/webpack

Low-level webpack 5 loader for [style-this](https://style-this.usagi.io), zero-runtime CSS-in-JS.

> Experimental. There's no turn-key webpack plugin yet, for Next.js use
> [`@style-this/next`](https://www.npmjs.com/package/@style-this/next), which is built on this loader.

```bash
pnpm add @style-this/core @style-this/webpack
```

| Export | Description |
| --- | --- |
| `default` | loader transforming JS/TS modules |
| `NextCSSLoader` | companion loader serving the generated CSS |

Documentation: [style-this.usagi.io/reference/next-webpack/](https://style-this.usagi.io/reference/next-webpack/)
